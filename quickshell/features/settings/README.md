Settings application, navigation, reusable controls, About pages, and general settings views.

## Naming

- Settings pages and their QML types end in `Settings` (for example, `BarSettings.qml`).
- Saved-state files and their types end in `State` (for example, `ShellState.qml`).
- Backends end in `Service`; `*Service.qml` names are unchanged.
